# RealDating 💕

A polished, responsive dating website starter designed for real-world expansion.

## Included
- Responsive landing page and discovery experience
- Profile creation demo using browser localStorage
- Safety-focused UI and 18+ messaging
- GitHub Pages-ready static site

## Make it a real multi-user app
Add Supabase or Firebase for authentication, profiles, photo uploads, likes, mutual matches, real-time chat, blocks and reports. A suggested data model is: profiles, photos, likes, matches, messages, blocks, reports.

## Deploy with GitHub Pages
Open repository Settings → Pages → Deploy from a branch → main → /(root) → Save. No build step is required.

## Production checklist
Before opening registration publicly, add server-side authentication, authorization/RLS, moderation, age verification appropriate to your jurisdiction, secure image handling, rate limits, and privacy/terms pages.
